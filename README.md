# tailwind--practice
A classic but simple design of a user friendly form using tailwind css

## 📁 Project Workspace Layout
* `src/input.css` - Raw style entrypoint containing baseline layout injections.
* `dist/index.html` - Production ready user interface layout.
* `dist/style.css` - Final compiled distribution styles.

## 🛠️ Architecture Highlights
* **Tailwind Configuration**: Scans distribution directories dynamically.
* **Palette Configuration**: Slate canvas highlighted with strict emerald interactive states.
* **Input States**: Smooth transition shifts when inputs gain active focus.
